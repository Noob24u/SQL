Customer Care Analytics — Zendesk Support Metrics

Sample dashboard built on synthetic data, shaped to match the schema of core_all_brands__zendesk_ticket_metrics and core_all_brands__zendesk_new_open_ticket_daily in this repo. The real production dashboards for this data lived in Mode Analytics / Metabase and aren't accessible outside that company's account — this reconstructs the same KPI set on made-up numbers so the metrics defined in the dbt models can be seen visually.

New & open tickets — last 30 days

Daily count of tickets in "new" or "open" status, all brands combined.

Tickets by contact reason

Primary reason mapped from the ticket form, last 30 days.

Resolution touch mix by brand

Share of tickets resolved in 1, 2, or 3+ public agent replies.

Brand / country breakdown

Core KPIs from core_all_brands__zendesk_ticket_metrics, last 30 days.

Metric definitions: FRT (First Response Time) = time to first internal comment on a non-proactive ticket · AHT (Avg. Handling Time) = agent time actively worked on a ticket · Contact rate = tickets ÷ orders shipped in the same period · 1-touch resolution = solved in fewer than 2 public agent replies. All figures on this page are synthetic and for illustration only.
